# 東區房市觀察

臺南市東區、交易日期自 2026-06-01 起的成屋買賣分析。資料取自內政部官方，不含預售屋與租賃。

## 直接使用

開啟 `public/index.html` 即可使用。網站已附實際資料，無須安裝套件。也可使用 `python -m http.server 8765 --directory public`。

## 更新

Python 3.10+，無第三方套件：

```
python update.py
python test_data.py
```

程式下載官方季度及逐期檔案，保留台南 CSV 快取、依編號去重，原子替換網站資料。下載或格式檢查失敗時保留上次網站資料並回傳非零退出碼。不要刪除 cache，舊期資料退出官方近期清單後需由快取保留。

## 公開與雲端更新（已啟用）

正式網站：https://aston45gg.github.io/tainan-east-housing/

專案：https://github.com/Aston45GG/tainan-east-housing

GitHub Pages 與 GitHub Actions 已啟用。每日台灣時間約 04:30 下載官方當期資料、檢查並發布；排程可能延遲。可在 Actions 手動執行 Update official data and publish。首次執行已於 2026-09-23 成功通過。

更新失敗會保留上次網站；請在 GitHub 通知設定開啟 Actions 失敗通知。

公開內容限 public 資料夾。網站不含私人帳號或分析筆記。部署服務的用量、費用與規則以所選帳號方案為準。

## 計算與限制

- 所有圖表套用相同篩選。每坪單價使用官方單價換算；總價與建物面積包含車位。
- 預設排除所有非空備註，可能一併排除普通說明案件，使用者可取消。
- 官方資料有補登及更正；同編號新資料覆蓋舊資料，撤銷案件尚未自動核對，不保證與官方動態查詢完全一致。
- 初始 115S2 涵蓋登記日至 2026-06-10，搭配 2026-07-01 起逐期資料銜接。交易日和登記日不同。
- 屋齡以成交時估算；缺漏屋齡在套用上限時排除。
- 原始官方檔案及快取僅供重現；網站不提供估價或投資預測。
