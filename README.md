# 東區房市觀察

臺南市東區實價分析，成屋自 2026-01-01 起、預售屋自 2026-01-01 起，依交易日期分別統計。資料取自內政部官方，不含租賃。

預售屋頁面：https://aston45gg.github.io/tainan-east-housing/presale.html

兩類市場皆提供月報、單坪價格前三名、條件篩選與 CSV 下載。預售屋額外提供建案名稱、棟及號搜尋，且不計算屋齡。執行 `update.py` 會同時更新成屋與預售屋。

預售屋會排除已下載資料中標示解約的案件，但未另外接入完整解約異動清單，後續解約可能尚未反映。官方原始快取保留原文；依使用者確認，網站將「國城?實」顯示為「國城寶實」，後續更新也套用此名稱對照。

## 直接使用

開啟 `public/index.html` 即可使用。網站已附實際資料，無須安裝套件。也可使用 `python -m http.server 8765 --directory public`。

## 更新

Python 3.10+，無第三方套件：

```
python update.py
python test_data.py
```

程式下載官方季度及逐期檔案，保留台南 CSV 快取、依編號去重，原子替換網站資料。下載或格式檢查失敗時保留上次網站資料並回傳非零退出碼。不要刪除 cache，舊期資料退出官方近期清單後需由快取保留。

## 計算與限制

- 所有圖表套用相同篩選。每坪單價使用官方單價換算；總價與建物面積包含車位。
- 預設排除所有非空備註，可能一併排除普通說明案件，使用者可取消。
- 官方資料有補登及更正；同編號新資料覆蓋舊資料，撤銷案件尚未自動核對，不保證與官方動態查詢完全一致。
- 初始 115S1 與 115S2 涵蓋年初至 2026-06-10 的登記資料，搭配 2026-07-01 起逐期資料銜接。交易日和登記日不同。
- 屋齡以成交時估算；缺漏屋齡在套用上限時排除。
- 原始官方檔案及快取僅供重現；網站不提供估價或投資預測。

## 建案分析

`public/projects.html` 提供國城寶實棟別、房型、樓層與價格比較。資料來自使用者提供的 Excel，保留 2025-07-16 至 2026-07-31 完整期間，554 筆中排除 5 筆解約，共 549 筆有效交易。此為獨立快照，不隨官方下載排程更新、不與官方頁面合併。匯入時逐組核對工作簿摘要。
